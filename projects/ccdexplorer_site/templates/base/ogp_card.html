{# One place that decides what a shared ccdexplorer link looks like. `entity` is the same `//` triple the page already lives at. That is deliberate: the card route takes the same shape, so a page's preview image is always derivable from the page's own address and the two can never drift apart. The card itself is rendered by the site at /og//image.png -- see app/routers/og.py. That is the same shape the statistics charts already use (/plots///image.png, tagged by base/plots_og.html), and the tag set below matches that template's. It deploys with these templates, so there is nothing to feature-flag: if the route is there, the image is. #} {% macro ogp_card(env, entity, title, description=None, type="website") -%} {#- SITE_URL is unset in a local .env, and Jinja renders None as the literal string "None" -- which is how a verification email once went out pointing at None/verify/... . An empty base gives relative URLs instead: not what the OG spec wants, but nothing crawls a laptop, and it can never become a link to a host called None. #} {%- set base = env.SITE_URL or "" %} {%- if description %} {%- endif %} {%- set card = base ~ "/og/" ~ entity ~ "/image.png" %} {%- if description %} {%- endif %} {%- endmacro %}
